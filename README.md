# Controle Financeiro — Trem de Minas

Revise a política com a empresa, confirme as práticas de segurança, retenção e fornecedores, retire o aviso de minuta e ajuste a vigência antes de publicar.

1. Crie um repositório público separado chamado `controle-financeiro-public` em https://github.com/new.
2. Envie o arquivo `index.html` para a branch `main`.
3. Em Settings → Pages → Build and deployment, selecione Deploy from a branch, `main` e `/ (root)`, e salve.
4. Abra a URL exibida pelo GitHub Pages em uma janela anônima. Copie a URL pública para a Meta.

Não publique código privado, dados financeiros ou credenciais.
